## Evidence added

### Perfetto

Source type: official project documentation.

Verified 2026-08-20:

- profiling statistically samples resource use and is distinct from time-ordered tracing;
- metrics are more appropriate than heavyweight traces for continuous long-term observation when trace cost is unacceptable;
- Perfetto supports Android/Linux system tracing, CPU call-stack sampling, counters, heap profiling, app instrumentation and multi-source correlation;
- Trace Processor/PerfettoSQL supports programmatic analysis and an explicit workflow from interactive exploration to automated analysis;
- out-of-box system-level tracing support is not equivalent across operating systems: Android/Linux are documented system-trace targets, while Windows/macOS lack the same integrated system data sources.

Sources:

- https://perfetto.dev/docs/
- https://perfetto.dev/docs/tracing-101
- https://perfetto.dev/docs/quickstart/callstack-sampling
- https://perfetto.dev/docs/getting-started/system-tracing
- https://perfetto.dev/docs/quickstart/trace-analysis

### Go pprof and PGO

Source type: official Go documentation.

Verified 2026-08-20:

- runtime/pprof and net/http/pprof expose CPU, heap, goroutine, block, mutex and related profile classes;
- `go tool pprof` analyzes runtime profile data;
- production profiling is supported but adds cost and should have overhead measured before broad use;
- some profile collection modes interfere with each other;
- Go PGO consumes CPU pprof profiles and explicitly treats workload representativeness as critical; unrepresentative profiles can provide little/no production benefit.

Sources:

- https://go.dev/doc/diagnostics
- https://go.dev/doc/pgo

### JDK Flight Recorder 26

Source type: Oracle official JDK 26 documentation.

Verified 2026-08-20:

- JFR records JVM/application/OS event data and has configurable event sets;
- `default.jfc` is documented for continuous recording with typical overhead below 1%, while `profile.jfc` records more profiling data;
- actual overhead remains workload/configuration dependent and Oracle recommends measuring it with application performance tests;
- Heap Statistics can add significant overhead by triggering old GC cycles;
- method attribution is sampling-based and can be inaccurate when sample count is low.

Sources:

- https://docs.oracle.com/en/java/javase/26/jfapi/flight-recorder-configurations.html
- https://docs.oracle.com/en/java/javase/26/troubleshoot/troubleshoot-performance-issues-using-jfr.html
- https://docs.oracle.com/en/java/javase/26/jfapi/index.html

### Windows Performance Toolkit

Source type: Microsoft official documentation.

Verified 2026-08-20:

- WPR records ETW system/application events and can be driven through UI or command line with built-in/custom recording profiles;
- WPA analyzes ETL recordings and provides system-wide performance evidence rather than only a language-runtime view.

Sources:

- https://learn.microsoft.com/en-us/windows-hardware/test/wpt/
- https://learn.microsoft.com/en-us/windows-hardware/test/wpt/introduction-to-wpr
- https://learn.microsoft.com/en-us/windows-hardware/test/wpt/windows-performance-analyzer

### Microsoft ETW MCP Early Preview

Source type: Microsoft official documentation; Early Preview.

Verified 2026-08-20; documentation last updated 2026-08-14:

- ETW MCP is a local/headless MCP server for natural-language ETL analysis with GitHub Copilot or other MCP-capable AI assistants;
- documented tools/workflows include trace processing, data-source discovery, CPU/time/process queries, A/B comparison, critical-path work, hot stacks and repeatable batch/CI investigations;
- the server exposes structured trace-processing tools rather than streaming raw events directly to the model;
- Microsoft explicitly states that LLM interpretation can vary, be incomplete, or be wrong and instructs users to validate important conclusions against underlying trace tables/graphs/time ranges/stacks;
- feature behavior, availability and supported scenarios can change during Early Preview.

Source:

- https://learn.microsoft.com/en-us/windows-hardware/test/wpt/etw-mcp-early-preview-july-2026
