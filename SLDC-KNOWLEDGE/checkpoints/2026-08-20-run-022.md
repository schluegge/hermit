## Contradiction / falsification pass

1. **Stable version:** Godot 4.7.1 is a stable maintenance release. Godot 4.7.2 was only RC in the checked 2026-08-03 primary source. RC behavior was not promoted to stable evidence.
2. **Testing:** GUT is listed in Godot's Asset Library as Community, so it is not represented as first-party/built-in engine testing.
3. **GUT version scope:** GUT maintainer documentation explicitly maps 9.7.1 / `godot_4_7` to Godot 4.7.x. The Asset Library may expose an older 4.6-targeted GUT package; this is treated as distribution/version lag, not evidence that 9.7.1 is incompatible.
4. **GdUnit4:** Asset Library 6.2.0 is described as built on Godot 4.5. No checked source established 4.7 compatibility, so it remains unresolved.
5. **Headless:** no claim that headless execution validates renderer/display/GPU behavior.
6. **Profiler:** no claim that profiled performance equals normal-run performance; official docs state profiling is performance-intensive.
7. **Export:** successful export is kept separate from gameplay/runtime/platform-certification correctness.
8. **LSP:** the `GDScriptLanguageProtocol` class is experimental and explicitly not an LSP client; no broad client-compatibility claim was inferred.
