### Apple Instruments / `xctrace`

Verified from current Apple documentation:

- Xcode's command-line reference documents `xctrace` to record, import, export and symbolicate Instruments `.trace` files.

### NVIDIA GPU-native profiling

Verified from current NVIDIA documentation:

- Nsight Systems captures CUDA API calls and GPU workload activity such as kernel execution and memory operations on a timeline.
- Nsight Systems supports post-collection CLI/GUI analysis and `nsys export`; NVIDIA states `.nsys-rep` is the forward-compatible report format while exported SQLite schema can change.
- Nsight Compute 13.3 is a CUDA kernel profiler with UI/CLI, detailed metric collection, report comparison, rules and scripting/report interfaces.
- Nsight Systems and Nsight Compute therefore represent distinct system/timeline and kernel-level evidence planes.

Sources, verified 2026-08-20:

- NVIDIA official: https://docs.nvidia.com/nsight-systems/UserGuide/index.html
- NVIDIA official, 2026.4.1 release notes: https://docs.nvidia.com/nsight-systems/ReleaseNotes/index.html
- NVIDIA official, Nsight Compute 13.3: https://docs.nvidia.com/nsight-compute/
- NVIDIA official: https://docs.nvidia.com/nsight-compute/ProfilingGuide/index.html

### Performance CI / statistical regression evidence

Verified from current Google Benchmark documentation:

- warmup, minimum runtime and repeated benchmark runs are supported;
- repeated runs report mean, median, standard deviation and coefficient of variation;
- JSON output preserves machine/context and per-benchmark evidence;
- `compare.py` compares baseline/contender results and supports Mann–Whitney U testing with sufficient repetitions;
- project documentation explicitly warns that measurements are noisy, visual inspection is insufficient and the U test requires a large repetition count (documented as no less than 9) to be meaningful;
- statistical significance is not equivalent to practical significance or causal diagnosis.

Sources, verified 2026-08-20:

- Google Benchmark official: https://google.github.io/benchmark/user_guide.html
- Google Benchmark official: https://google.github.io/benchmark/tools.html
- Maintainer repository: https://github.com/google/benchmark
