### PostgreSQL 18

Source type: official PostgreSQL documentation.

Verified 2026-08-20:

- `CREATE INDEX CONCURRENTLY` permits continued inserts/updates/deletes but performs more work and has failure/invalid-index caveats;
- `NOT VALID` followed by `VALIDATE CONSTRAINT` separates constraint introduction from historical validation and has explicit lock semantics.

Sources:

- https://www.postgresql.org/docs/current/sql-createindex.html
- https://www.postgresql.org/docs/current/sql-altertable.html

### MySQL 8.4

Source type: official Oracle/MySQL reference documentation.

Verified 2026-08-20:

- `ALGORITHM` and `LOCK` support is operation-specific;
- some DDL can be instant or in-place while permitting concurrent DML, while other operations rebuild tables or disallow concurrent DML;
- explicit `LOCK=NONE` / algorithm requirements fail if unsupported rather than proving the requested concurrency is universally available;
- online DDL has documented failure conditions involving locks, disk space, online-log exhaustion, and concurrent writes incompatible with the new definition.

Sources:

- https://dev.mysql.com/doc/refman/8.4/en/innodb-online-ddl.html
- https://dev.mysql.com/doc/refman/8.4/en/innodb-online-ddl-operations.html
- https://dev.mysql.com/doc/refman/8.4/en/innodb-online-ddl-failure-conditions.html
