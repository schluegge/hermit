## Contradiction / falsification pass

1. **Drift versus impact:** drift is a distribution signal and is not treated as proof of quality/business degradation.
2. **Alert versus root cause:** a threshold event is not represented as diagnosis.
3. **Retraining versus fix:** a retrained candidate can still be worse; retraining success is not promotion evidence.
4. **Ground truth latency:** model-quality monitoring may depend on labels that arrive later; no assumption of immediate labels is made.
5. **Vertex scope:** v2 Preview/tabular-only is preserved; no GA/all-modality claim is made.
6. **AWS lifecycle:** the 2026-07-30 new-customer closure is preserved; Model Monitor is not presented as a universal new-deployment recommendation.
7. **Registry versus serving state:** approval/version metadata is not equated with the runtime model actually serving traffic.
8. **Automation versus authority:** Azure proves an event can start retraining; AWS proves approval can control CI/CD eligibility. Neither establishes universal autonomous production promotion.
9. **Cross-vendor semantics:** Azure/Vertex/AWS metric names are not declared mathematically equivalent without direct definition-level reconciliation.
10. **AI authority:** no checked primary source proves an AI agent should autonomously approve a production model. AI remains assistive or an executor of explicitly authorized deterministic tools/policies.
