## Contradiction / falsification pass

Explicitly preserved:

- SBOM/inventory != vulnerability scan.
- Vulnerability record != scanner finding.
- Finding != exploitability/reachability.
- Alias/source overlap != independent corroboration.
- OSV package/version/PURL matching != NVD CPE matching.
- More enabled vulnerability feeds != automatically better evidence.
- Clean known-vulnerability scan != absence of vulnerabilities.
- Policy pass/no FAIL != proof of security.
- Dependency upgrade proposal != verified remediation.
- Initial Dependency-Track policy evaluation may lack asynchronously populated inputs; missing data must not be silently interpreted as healthy.
