## Research additions

### AMD ROCprofiler-SDK / `rocprofv3`

Verified from current AMD ROCm documentation:

- ROCprofiler-SDK is the current tooling infrastructure for tracing ROCm GPU applications and collecting low-level kernel hardware counters.
- `rocprofv3` can trace applications and collect kernel counters without source modification.
- Current quick-reference documentation includes target capability/counter discovery.
- Legacy ROCProfiler, ROCTracer, `rocprof`, and `rocprofv2` are deprecated; AMD recommends ROCprofiler-SDK/`rocprofv3` and anticipates legacy end-of-support by the end of 2026 Q2.

Primary sources, verified 2026-08-20:

- https://rocm.docs.amd.com/projects/rocprofiler-sdk/en/latest/
- https://rocm.docs.amd.com/projects/rocprofiler-sdk/en/latest/how-to/using-rocprofv3.html
- https://rocm.docs.amd.com/projects/rocprofiler-sdk/en/latest/quick-reference/quick_guide.html
- https://rocm.docs.amd.com/projects/rocprofiler/en/latest/

### AMD ROCm Compute Profiler

Verified from current AMD documentation:

- ROCm Compute Profiler is a kernel-level ML/HPC profiler built on ROCprofiler-SDK.
- It collects hardware performance counters and supports analyses including System Speed-of-Light, hardware-block-level Speed-of-Light, memory analysis, roofline analysis and baseline comparisons.
- Current primary target scope is AMD Instinct MI300/MI200/MI100; Radeon/RDNA support is documented as development in progress.
- `rocprof-compute profile` supports automated collection with machine-processable raw output formats and filtering.

Primary sources, verified 2026-08-20:

- https://rocm.docs.amd.com/projects/rocprofiler-compute/en/latest/
- https://rocm.docs.amd.com/projects/rocprofiler-compute/en/latest/what-is-rocprof-compute.html
- https://rocm.docs.amd.com/projects/rocprofiler-compute/en/latest/how-to/profile/mode.html

### Intel VTune GPU analysis

Verified from current Intel 2026 documentation:

- VTune GPU Offload analysis correlates CPU/GPU execution and helps distinguish CPU-bound from GPU-bound workloads.
- Supported collection includes GPU usage/timeline evidence and programming-API tracing for supported SYCL, Level Zero and OpenCL workloads.
- GPU Compute/Media Hotspots provides more focused kernel-level analysis for supported GPU workloads.
- Some current accelerator-analysis capabilities are preview features and therefore version/status-scoped.
- API tracing may perturb CPU-side performance and was recorded as a measurement caveat.

Primary sources, verified 2026-08-20:

- https://www.intel.com/content/www/us/en/docs/vtune-profiler/user-guide/2026-0/gpu-offload-analysis.html
- https://www.intel.com/content/www/us/en/docs/vtune-profiler/user-guide/2026-0/accelerators-group.html

### Intel GPA lifecycle correction

Current Intel product documentation states that Intel Graphics Performance Analyzers 2025.1 is the final version, with no further feature/security fixes and discontinuation in 2026. Intel points compute-profiling users toward VTune. Therefore GPA remains historical/specialized evidence for supported graphics workflows but is not represented as an actively maintained 2026 default.

Primary sources, verified 2026-08-20:

- https://www.intel.com/content/www/us/en/developer/tools/graphics-performance-analyzers/overview.html
- https://www.intel.com/content/www/us/en/docs/gpa/user-guide/2025-1/overview.html
